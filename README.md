# Hockeytactiek voor kids 🏑

Een interactieve, Nederlandstalige uitlegpagina over veldhockeytactiek, gemaakt voor jonge spelers (en hun coaches en ouders). Met **bewegende tekeningen** op een hockeyveld: druk op **Speel af** en zie hoe posities, opbouw, verdedigen en de strafcorner werken.

De hele site zit in één bestand (`index.html`) — geen installatie, geen build, geen extra mappen.

## 📚 Wat zit erin

1. **Posities** — klikbaar veld (4‑3‑3); tik op een speler voor zijn/haar taken.
2. **Opbouwen van achteruit** — driehoekjes, breedte maken, binden en spelen.
3. **Vrijlopen & driehoekjes** — je vrijlopen uit de dekking.
4. **Aannemen & passen** — de push, open aannemen, in de loop spelen.
5. **Verdedigen** — open staan, binnenkant dekken, de W‑vorm, samen jagen.
6. **Spelsituaties** — 2‑tegen‑1 overtal + kaarten met veelvoorkomende momenten.
7. **Aanvallen** — 1‑tegen‑1 passeren en de voorzet met afronden.
8. **Druk zetten & omschakelen** — samen pressen en de snelle tegenaanval.
9. **De strafcorner** — aanvallen én verdedigen (3‑1), met een jeugd‑kader.
10. **Oefeningen** — 16 kant‑en‑klare trainingsoefeningen met "zo zet je 't op" en "waar let je op".

In totaal **12 animaties** en een klikbaar posities‑veld. De pagina is responsive (werkt op mobiel), toetsenbord‑toegankelijk, en respecteert de instelling "verminderde beweging".

## 💻 Lokaal openen

Download `index.html` en dubbelklik het — het opent in elke moderne browser. Internet is alleen nodig voor de lettertypes (Google Fonts).

## 🚀 Hosten op GitHub Pages (gratis)

1. Maak een **publieke** repository.
2. Upload `index.html` in de **hoofdmap** (Add file → Upload files → Commit).
3. Ga naar **Settings → Pages**, zet Source op **Deploy from a branch**, kies **main** en **/ (root)**, en Save.
4. Wacht ± 1 minuut en open de groene link die bovenaan verschijnt.

## 🔄 Bijwerken

Upload een nieuwe `index.html` over de oude heen (Add file → Upload files → Commit). De site vernieuwt vanzelf binnen een minuut.
